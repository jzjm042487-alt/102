# 蛇形管排料项目 交接文档 & 标准流程

更新时间：2026-10-13 21:30（北京时间）
代码仓库：https://github.com/jzjm042487-alt/102

## 一、角色定义
- **算法负责人（数学专家 & 算法专家）**：定义问题模型与算法方向、写开发任务说明、做测试验收与专业判断。不直接写代码。
- **编程执行（Cursor 云端助手 / Cursor 编辑器）**：按任务说明改代码、跑评测、开 PR。
- **宋杰（决策人）**：确认业务规则、拍板方向、启动 Cursor 任务。
- 原则：工业上要**稳定可用**，不要"漂亮设计但解决不了具体问题"。先稳定出解，再谈优化。

## 二、标准工作流程
1. **澄清业务规则**：凡是代码里有分歧的假设，先列成问题让宋杰确认，结论记入本文档第三节。
2. **写任务说明**（markdown）：背景、已确认规则、本阶段唯一目标、硬指标、不做什么、交付物。
3. **Cursor 执行**：把任务说明丢给 Cursor，要求新分支、勤 commit/push、开 PR，报告写到 `docs/`。
4. **验收**：读 PR 报告与 CSV，按硬指标判断通过/不通过，给出专业结论与下一步。
5. **不达标时先诊断再改**：对照老软件的解归类失败原因，不盲目加策略。
6. 每一轮结束更新本文档。

## 三、已确认的业务规则
- 一维、有限库存、先切后焊；物料组（材质+规格）独立求解。
- 锯缝 BladeMargin 默认 **5 mm**（与老软件一致），不含在零件长度内；求解器与校验器必须同一默认值。
- 焊口上限 = 输入 `Max_Weldingjoint_Number`，**取消** `L//3000` 与 13 的钳制（老软件没有）。
- `Min_Welding_Length` 暂不作约束。
- 禁焊区 `Unweldable_Area`：**闭区间，端点也禁止焊接**，无余量可放宽。
- 必用料规则：**取消**（老软件不强制），已做成开关 `NestParam.EnforceMustUse`，默认关。
- 整根不焊算一种拼法。
- 利用率目标只作报告，不是硬约束。
- 管型身份：需求用 `Parent_node|jlxh|cube_no`；对照老软件焊口时用 `figure_number|jlxh|cube_no`（老软件输出无 Parent_node）。待宋杰最终确认。
- 老软件早期单题可计算十几个小时 → 正式验收不应以 60 秒为硬截止。
- 优化目标（下一阶段再做）：用料最少 → 焊口最少 → 拼法种类最少 → 切法种类最少（逐级锁定）。
