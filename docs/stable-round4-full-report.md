# 第四轮 stable 可行性全量

评测全集仍是 1591 条。策略链和目录 CP-SAT 的顺序与预算没有改。按需生成（`ondemand-pricing`）只在这两段都没有返回计划之后运行，独立时钟，默认每题 60 秒，调用方用 `ondemand_time_limit` 修改，`0` 表示关掉。

**15 秒策略链 + 独立 15 秒目录 CP-SAT + 独立 60 秒按需生成：1503 / 1591 = 94.47%。** 95% 对应 1512 / 1591，这次还差 9 条。新解出的 54 条全部来自按需阶段，并且都通过了独立校验。

不把目录缺口或超时写成 `INFEASIBLE` 或 `OPTIMAL`。本路径的 `optimality_claimed`、`lexicographic_optimal`、`core_lexicographic_optimal` 仍为假。默认引擎仍是 baseline。

## 方法

按需阶段在 `backend/app/engine_stable_ondemand.py`。焊口不是自由整数，而是离散网格、禁焊区端点外移 1 毫米，以及定尺互补。字母表从 16 起逐档翻倍；每轮新段长、每管拼法数和切法列上限随档放宽。受限主问题不可行时，用没有拼法的管子和切不出来的段长补列，直到找到解或到点。

这个文件不按题号、物料组或某一题的段长分支。必用料打开时，这一阶段跳过。

仍沿用的暂定业务规则没有改默认值：刀缝默认 5 毫米，输入里写了就用输入值；不套「长度除以 3000」的焊口帽；`Min_Welding_Length` 在 stable 路径上不是约束；`EnforceMustUse` 默认关闭；禁焊区是闭区间；分母是 1591。
