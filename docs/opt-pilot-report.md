## 结论

50 条全部重新解出，独立校验通过，四项整数与第五轮正式结果一致。37 条换成了更优方案，13 条保留起点。没有任何一条词典序差于起点，也没有校验失败。

相对起点，50 条合计少用料 17,754,134 毫米，少 842 个焊口，拼法种类多 53，切法种类少 36。用料在 35 条上下降，在 0 条上上升。

对老软件的词典序由 胜 0、平 0、负 50 变为 胜 4、平 0、负 46。四条由负转胜的记录号是 600、1031、2856、2888。其余 46 条仍然用料多于老软件，合计仍多 23,629,292 毫米。

这次试算不声称全量胜场不少于负场，也不重新测量 95.60% 的覆盖率。这 50 条都留在已解集合里。
